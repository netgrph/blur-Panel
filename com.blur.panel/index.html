Set up "Blur Panel HQ" template

We bundle a ready-made Blur Panel HQ template (H.264 at maximum bitrate). Click Open Template Editor below — we'll copy the template file path to your clipboard. Then in AE:

  1. In the Output Module Templates dialog, click Load…
  2. In the file dialog, press Ctrl + V to paste the path, then Enter.
  3. Click OK to close the templates dialog.
  4. Back here, click Verify.
